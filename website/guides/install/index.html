Install Vaaluation on Mac

Set up the app, grant its one required permission, and check your first item.

On this page

  • Download and install
  • Enable Accessibility permission
  • Run your first price check
  • If something does not work

Before you install

You need macOS 14 Sonoma or later and the English Path of Exile 1 client. Use Windowed or Windowed Fullscreen mode in the game. The current release targets PoE 1; PoE 2 support is not advertised.

Download and install

  1. Open the latest GitHub release and download the application ZIP from its Assets section.
  2. Unzip the download, then drag Vaaluation.app into Applications.
  3. Launch Vaaluation from Applications. It runs as a menu-bar app, so look in the macOS menu bar rather than the Dock.

Published releases are signed with an Apple Developer ID certificate and notarized by Apple. You do not need Xcode or Node.js to use a release download.

Enable Accessibility permission

Vaaluation needs Accessibility permission to send the item-copy keystroke to Path of Exile when you press the price-check shortcut.

  1. Open System Settings → Privacy & Security → Accessibility.
  2. Add /Applications/Vaaluation.app if it is not listed, and switch its permission on.
  3. Quit and reopen Vaaluation so it re-reads the permission.

The app does not require Screen Recording or Input Monitoring permission.

Run your first price check

  1. Open the English Path of Exile client in Windowed or Windowed Fullscreen mode.
  2. Hover over an item in your inventory.
  3. Press Ctrl + D to see comparable trade listings.
  4. Check that the selected league matches your character’s league.

Use Ctrl + Option + D to keep the overlay open while adjusting filters. Read the item price-checking guide for help interpreting results.

If something does not work

Start with the troubleshooting guide for missing windows, shortcuts, permissions and empty searches. For source builds, follow the repository build instructions.
