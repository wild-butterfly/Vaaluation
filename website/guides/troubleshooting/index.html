Vaaluation troubleshooting on macOS

Work through common setup and search issues, then collect useful details if you need help.

The app opens but I cannot find a window

Vaaluation is a menu-bar app with no Dock icon and no window on launch. Look for its icon in the macOS menu bar. Opening the app again from Finder or Spotlight opens the main window. The default Shift + Space shortcut shows or hides the panel.

Ctrl + D does not check my item

  1. Shortcuts are active only while Path of Exile is in front. Make sure Path of Exile is in focus and your pointer is over an inventory item.
  2. Use Windowed or Windowed Fullscreen mode.
  3. Check System Settings → Privacy & Security → Accessibility and enable the installed Vaaluation app.
  4. Quit and reopen Vaaluation after changing permission.
  5. Check the shortcut in Vaaluation Settings. If another app uses the same combination, choose a different binding.

If you built the app with ad-hoc signing, macOS can treat each rebuild as a new program. Remove the old Accessibility entry and add the rebuilt app again. See the permission setup instructions.

The item cannot be read

The parser expects the English Path of Exile 1 client. Check the game language and hover the item before pressing the shortcut. Confirm that Accessibility permission is enabled so the app can send the advanced item-copy keystroke.

If one item consistently fails while others work, include its English advanced item text in a bug report. You can copy that text in the game with Ctrl + Option + C.

The search returns no comparable items

Check the selected league first. Reduce the number of selected modifiers or widen their ranges; a very specific combination may have no current listings. Review the active filters if the app loosens a search automatically. See how to refine a price check.

An empty search is not evidence that an item has no value. It may simply have no close listed comparisons in that league.

Prices do not load or the service is rate limited

Vaaluation uses the official Path of Exile trade service. Check your connection and whether the official trade website loads in your browser.

If you see a rate-limit message, allow its indicated wait to finish before retrying. Repeated searches can extend the problem. Service errors may need time to recover; changing item modifiers will not fix a network outage.

Incoming trade requests do not appear

Trade-request watching is off by default. Enable it in Settings and check the configured game chat-log path. The watcher reads new requests from the point it is enabled; it does not import your old chat history. It recognises the game’s English trade-whisper wording.

Report a reproducible issue

If the problem continues, open a GitHub issue with your Vaaluation version, macOS version, the steps to reproduce it and the exact error text. For search problems, include the league and relevant item text. Review screenshots and logs for private information before sharing them.
