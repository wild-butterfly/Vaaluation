Ready in a few minutes

Install Vaaluation on your Mac

  1. Download the latest signed and notarized ZIP from GitHub.
  2. Unzip it and drag Vaaluation.app into Applications.
  3. Launch it and grant Accessibility permission when macOS asks.
  4. Use Windowed or Windowed Fullscreen mode in Path of Exile, then press Ctrl + D.

Questions

Vaaluation FAQ

Does Vaaluation work on Mac?

Yes. Vaaluation is purpose-built for macOS 14 Sonoma or later.

Is Vaaluation free?

Yes. It is free and open source under the MIT license, with no accounts, telemetry or paid tier.

Is the download safe?

Releases are signed with an Apple Developer ID certificate and notarized by Apple. You can also inspect the complete source code on GitHub.

Does it support Path of Exile 2?

The current release targets Path of Exile 1 on macOS. PoE 2 support is not advertised until the game and integration can be properly tested on Mac.
